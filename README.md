# 🛒 Aplicación Web de Gestión de Tienda

Aplicación desarrollada con **PHP, JavaScript, HTML y CSS** que permite la administración completa de una tienda, incluyendo registro de clientes y productos, gestión de ventas, y análisis de estadísticas comerciales.

## 🚀 Funcionalidades Principales

- **Dashboard de inicio**:
  - Muestra productos vendidos recientemente.
  - Estadísticas de mejores ventas.
  - Gráfico de compras por cliente.

- **Clientes**:
  - Registro y visualización de clientes.
  - Carga masiva de clientes mediante archivos CSV.

- **Productos**:
  - Registro de productos y visualización del inventario.
  - Carga masiva de productos mediante archivos CSV.

- **Ventas**:
  - Visualización de productos vendidos.
  - Registro de ventas de productos.
  - Consolidados de compras.
  - Historial de compras por cliente.

- **Estadísticas**:
  - Ranking de productos más vendidos.
  - Análisis gráfico de comportamiento de compras por cliente.

## 📂 Tecnologías Utilizadas

- **Backend**: PHP 8.0.0 o superior
- **Frontend**: HTML, CSS, JavaScript
- **Base de datos**: MySQL
- **Carga de datos**: Archivos CSV para productos y clientes

## ⚠️ Requisitos

- PHP versión **8.0.0** o superior
- Servidor web como **Apache** (puedes usar **Laragon**, **XAMPP**, etc.)
- Base de datos MySQL
- Extensiones habilitadas: `mysqli`, `mbstring`

## 📌 Nota

- Esta aplicación está orientada a pequeñas y medianas tiendas que deseen una solución simple, ligera y efectiva para llevar el control de ventas, clientes e inventario.
